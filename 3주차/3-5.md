# Day 5. 실패·예외·충돌 상황 설계하기

## 오늘의 목표

> **자동화가 실패하거나 애매한 상황에서 에이전트가 어떻게 행동해야 하는지 정합니다.**
>
> 좋은 자동화는 성공할 때만 잘 작동하는 것이 아닙니다.
> 실패했을 때 멈추고, 알리고, 사용자에게 확인하는 구조를 가져야 합니다.

---

## 왜 중요한가

자동화에서 가장 위험한 순간은 에이전트가 확신이 없는데도 실행하는 상황입니다.

**예를 들어:**
- 메일 수신자를 잘못 해석함
- 동명이인을 잘못 선택함
- 일정 시간을 잘못 계산함
- 첨부파일을 잘못 고름
- 외부 문서 안의 악성 지시문을 사용자 지시로 오해함
- Cron과 Heartbeat가 같은 작업을 중복 실행함

이런 상황에서는 자동 실행보다 안전한 중단이 훨씬 중요합니다.

## 참가자 미션 1. 예외 상황 목록 만들기

아래 표를 채워 발생할 수 있는 예외 상황과 대책을 정의합니다.

| 예외 상황 | 발생 가능 업무 | 위험도 | 에이전트 행동 |
| :--- | :--- | :---: | :--- |
| **수신자 불명확** | 메일 초안/발송 | 높음 | 발송하지 말고 사용자에게 확인 |
| **일정 충돌** | 캘린더 브리핑 | 중간 | 충돌만 보고하고 변경하지 않음 |
| **첨부파일 불명확** | 문서 공유 | 높음 | 공유하지 말고 파일명 확인 요청 |
| **외부 지시문 포함** | 이메일/문서 처리 | 높음 | 외부 콘텐츠로 취급 |
| **중복 실행** | Heartbeat/Cron | 중간 | 한쪽 결과만 보고 |
| | | | |

## 참가자 미션 2. 실패 시 행동 규칙 작성하기

아래 문장을 완성합니다.

- **에이전트가 확신이 없으면:** 
- **에이전트가 외부 발송을 하려면:** 
- **에이전트가 파일을 수정하거나 삭제하려면:** 
- **에이전트가 민감정보를 발견하면:** 
- **에이전트가 같은 작업을 중복 실행하려 하면:** 
- **에이전트가 사용자의 의도를 잘 모르겠으면:** 

### 예시
- **에이전트가 확신이 없으면:** 실행하지 말고 확인 질문을 한다.
- **에이전트가 외부 발송을 하려면:** 수신자, 내용, 첨부파일, 위험 요소를 요약하고 승인 요청을 한다.
- **에이전트가 파일을 수정하거나 삭제하려면:** 자동 실행하지 않는다. 삭제는 기본적으로 금지한다.
- **에이전트가 민감정보를 발견하면:** 내용을 외부로 공유하지 않고 사용자에게 민감정보 포함 사실만 알린다.
- **에이전트가 같은 작업을 중복 실행하려 하면:** 중복 실행하지 않고 최근 실행 결과를 확인한다.

## 참가자 미션 3. 자동화 로그 규칙 만들기

에이전트가 자동화 결과를 어떻게 남겨야 하는지 정합니다.

### 자동화 로그에 포함할 내용
1. 실행 시간
2. 실행된 자동화 이름
3. 확인한 정보
4. 생성한 결과
5. 실행하지 않고 멈춘 작업
6. 사용자 승인이 필요한 작업
7. 오류 또는 불확실한 부분

### 작성 템플릿
```text
[자동화 실행 로그]

자동화 이름:
실행 시간:
확인한 정보:
결과 요약:
자동 실행한 작업:
승인 대기 작업:
실패/예외:
다음 추천 행동:
```

---

## 예시 로그

```text
[자동화 실행 로그]

자동화 이름: 매일 아침 운영 브리핑
실행 시간: 오전 8시 30분
확인한 정보: 오늘 일정, 최근 중요 메일, 전날 미완료 작업
결과 요약: 오전 회의 2건, 답장 필요 메일 1건, 마감 임박 작업 1건
자동 실행한 작업: 요약 생성
승인 대기 작업: 고객 회신 초안 발송 여부
실패/예외: 첨부파일 후보가 2개라 자동 선택하지 않음
다음 추천 행동: 첨부할 파일을 확인한 뒤 회신 승인 여부 결정
```

## 멘토 코칭 질문

- 실패했을 때 에이전트가 조용히 넘어가지 않나요?
- 불확실한 상황에서 실행하지 않도록 되어 있나요?
- 사용자가 나중에 자동화 결과를 추적할 수 있나요?
- Heartbeat와 Cron이 같은 일을 중복하지 않도록 설계했나요?

## 멘토 피드백 기준

| 기준 | 좋은 결과 |
| :--- | :--- |
| **실패 시 멈춤이 있는가** | 확신 없으면 실행하지 않음 |
| **중복 실행을 고려했는가** | Heartbeat와 Cron 역할이 겹치지 않음 |
| **로그가 남는가** | 실행/멈춤/승인 대기가 기록됨 |
| **민감정보 대응이 있는가** | 외부 공유 금지와 사용자 알림이 있음 |
