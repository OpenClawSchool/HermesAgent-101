# HermesAgent-101: 4주 강의 커리큘럼 및 교재 저장소

![OpenClaw School](https://img.shields.io/badge/OpenClaw-School-blue?style=for-the-badge)
![Hermes Agent](https://img.shields.io/badge/Hermes-Agent-green?style=for-the-badge)

HermesAgent-101은 [WikiDocs Hermes Agent 가이드](https://wikidocs.net/book/19414)를 바탕으로, 일상 업무와 작은 개발 프로젝트를 Codex 하네스 구조로 바꾸도록 돕는 4주 강의용 책과 실습 커리큘럼을 관리하는 저장소입니다.

## 🚀 교육 목표

- Hermes Agent의 핵심 개념을 이해하고, Codex 하네스 실습 구조에 익숙해지기
- 일상 업무, 학습 과제, 문서 작업 등을 Agent/Skill/Orchestrator/Test/Evolution 구조로 설계하기
- 초보자 친화적인 한국어 설명을 바탕으로 직관적인 실습과 과제 수행하기
- 실행 하네스(Execution Harness) 생성 및 점검 파이프라인 경험하기

## 📚 커리큘럼 구성

이 저장소는 4주 과정의 강의 교재 원고와 실습 코드를 관리합니다.

| 차시 | 주차 | 핵심 내용 |
| :--- | :--- | :--- |
| **1주차** | **나의 AI 비서와 인사하기** | 설치, 첫 실행, CLI 기본기, 모델 라우팅, 텔레그램 연동, 반복 업무 자동화 후보 발굴 |
| **2주차** | **전문가 에이전트의 핵심 자산: Knowledge Base 설계** | USER·SOUL·MEMORY·AGENTS.md 파일 구조, 일반 LLM vs KB 연동 에이전트 차이, Obsidian 기반 지식 저장소 구축, AI 친화적 문서 포맷(Topic-Concept-Example-Checklist), PARA 기법 |
| **3주차** | **AI 비서를 직원으로 격상시키기: SOP와 자동화** | 비서(Assistant) vs 직원(Employee) 차이, GitHub Second Brain 구축, 근무일지 자동화(크론), 서브에이전트 설계 및 위임, ClawFlows 기반 SOP 자동화 레지스트리 |
| **4주차** | **에이전트 상품화 및 마켓플레이스 등록** | 에이전트 패키징과 브랜딩, AI 윤리 7원칙 및 보안 수칙, 마켓플레이스 등록 프로세스, 유·무료 정책 설계, 에이전트 이코노미 실현 |
