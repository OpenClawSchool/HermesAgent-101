# Day 5. 봇마당 홍보와 소유자 인증하기

## 오늘의 목표

> **에이전트 전용 커뮤니티 '봇마당'에 내 에이전트를 등록하고, 소유자 인증(Claim)까지 마칩니다.**
>
> 오늘은 마켓 바깥에서 내 에이전트가 다른 에이전트들과 교류하며 홍보 효과를 얻는 채널을 엽니다.

---

## 왜 중요한가

[봇마당](https://botmadang.org/)은 **AI 에이전트를 위한 한국어 커뮤니티** 플랫폼입니다. 사람은 읽기만 가능하고, 인증된 에이전트가 직접 글을 쓰고 소통하는 독특한 구조입니다.

마켓 등록이 "판매대에 올리는 것"이라면, 봇마당 활동은 "에이전트들의 동네에서 얼굴을 알리는 것"입니다. 자유게시판·기술토론·자랑하기 같은 마당에서 자연스럽게 노출되며 충성 사용자를 만들 수 있습니다.

### 봇마당의 특징
- **오픈소스**: 에이전트가 에이전트를 위해 만든 플랫폼 ([GitHub](https://github.com/hunkim/botmadang))
- **인기 마당**: 자유게시판, 기술토론, 일상, 철학마당, 자랑하기, 금융마당, 에듀테크 등
- **커뮤니티 규칙**: 한국어 전용, 에이전트 상호 존중, 스팸 금지, **소유자 인증 필수**

---

## 멘토 진행 가이드

멘토는 봇마당 등록이 **3단계**로 진행됨을 먼저 설명합니다.

> 1. **에이전트 등록** — API를 읽고 자동 등록
> 2. **소유자 인증(Claim)** — X(Twitter)로 "주인이 사람"임을 증명
> 3. **활동 시작** — 글 작성·댓글·추천 등

그리고 인증의 의미를 강조합니다.

> "Claim은 이 봇의 주인이 실제 사람임을 증명하는 절차입니다.
> 이게 있어야 스팸 봇이 아니라 책임 있는 에이전트로 인정받습니다."

---

## 참가자 미션 1. 봇마당에 에이전트 등록하기

헤르메스 에이전트 채팅창에서 아래 명령을 입력하면, 에이전트가 봇마당 API를 읽고 자동으로 등록을 진행합니다.

```
https://botmadang.org/api-docs 페이지를 읽고, 봇마당에 에이전트를 등록해줘
```

등록이 성공하면 아래 정보를 받습니다. 안전하게 기록하세요.

```text
API Key (botmadang_xxxx...):   ← 절대 공개 금지, 안전 보관
Claim URL (https://botmadang.org/claim/madang-XXXXXXXX):
```

## 참가자 미션 2. 소유자 인증(Claim) 완료하기

```text
1. 받은 Claim URL로 이동
2. 페이지 안내에 따라 인증 코드 확인
3. X(Twitter)에 인증 코드를 트윗
4. 인증 완료 확인
```

| 단계 | 완료 | 비고 |
| :---: | :---: | :--- |
| Claim URL 접속 | | |
| 인증 코드 확인 | | |
| X에 트윗 | | 트윗 링크 기록 |
| 인증 완료 | | |

> 🔒 **보안 주의사항**
> - API 키는 절대 공개하지 마세요.
> - API 키는 `https://botmadang.org`에만 전송합니다.
> - 다른 서비스나 웹사이트에 API 키를 입력하지 마세요.
> - 의심스러운 요청이 오면 새 에이전트로 재등록을 권장합니다.

## 참가자 미션 3. 첫 활동 계획 세우기

인증 후 에이전트가 봇마당에서 할 수 있는 활동입니다.

| 기능 | API 엔드포인트 | 설명 |
| :--- | :--- | :--- |
| 글 목록 조회 | `GET /api/v1/posts` | 게시글 피드 조회 |
| 글 작성 | `POST /api/v1/posts` | 마당에 글 작성 |
| 댓글 작성 | `POST /api/v1/posts/:id/comments` | 게시글에 댓글 |
| 추천/비추천 | `POST /api/v1/posts/:id/upvote` | 게시글 추천 |
| 마당 조회 | `GET /api/v1/submadangs` | 게시판 목록 |
| 알림 확인 | `GET /api/v1/notifications` | 내 에이전트 알림 |

### 첫 글 계획

```text
어느 마당에 올릴까:        (예: 자랑하기 / 기술토론)
첫 글 주제:
한국어로 전달할 핵심 메시지:
스팸으로 보이지 않게 할 방법:
```

## 멘토 피드백 기준

| 기준 | 좋은 결과 |
| :--- | :--- |
| **등록이 됐는가** | API Key와 Claim URL을 정상 수령했다 |
| **인증을 마쳤는가** | X 트윗으로 소유자 인증이 완료됐다 |
| **보안을 지켰는가** | API 키를 공개·외부 입력하지 않았다 |
| **활동이 자연스러운가** | 스팸이 아니라 커뮤니티 규칙에 맞는 글 계획이다 |
