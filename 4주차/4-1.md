# Day 1. 마켓 진입 전략과 AI 윤리·보안 점검하기

## 오늘의 목표

> **내 에이전트를 마켓에 올리기 전에, 어떤 플랫폼에 어떤 가치로 진입할지 정하고 AI 윤리·보안 기준을 통과시킵니다.**
>
> 오늘은 등록 버튼을 누르지 않습니다.
> 먼저 "이 에이전트를 세상에 내놓아도 되는가"를 점검하는 날입니다.

---

## 왜 중요한가

많은 사람이 에이전트를 만들면 곧바로 "어떻게 등록하지?"부터 찾습니다.
하지만 마켓은 실험작을 전시하는 곳이 아니라, 다른 사용자가 돈과 시간을 들여 신뢰하고 쓰는 **상품**이 거래되는 곳입니다.

그래서 등록보다 먼저 따져야 할 것이 있습니다.

### 마켓 진입 전 점검할 것
- 이 에이전트는 누구의 어떤 문제를 푸는가?
- 기존 인력 매칭(크몽·숨고)이나 일반 챗봇(GPTs)과 무엇이 다른가?
- 사용자에게 피해를 줄 수 있는 동작은 없는가?
- API 키나 민감정보를 안전하게 다루는가?
- 실패하거나 애매할 때 멈추고 사람에게 묻는가?

알바봇은 단순 인력 매칭이나 AI 챗봇을 넘어선 **AI 서비스 플랫폼**입니다. 내가 만든 에이전트가 나 대신 일하거나, AI가 못 하는 정교한 작업만 사람이 이어받는 **하이브리드 구조**와, 잘 훈련된 에이전트가 스스로 수익을 내는 **에이전트 이코노미**를 전제로 합니다.

---

## 멘토 진행 가이드

멘토는 참가자에게 이렇게 시작합니다.

> "오늘은 등록을 하지 않습니다.
> 대신 내 에이전트가 '상품'으로서 통과해야 할 기준을 먼저 세웁니다.
>
> 마켓에서 살아남는 에이전트는 기능이 화려한 것이 아니라,
> 믿고 맡길 수 있는 것입니다."

이후 다음 질문을 던집니다.

- 내 에이전트의 차별점을 한 문장으로 말할 수 있나요?
- 이 에이전트가 잘못 동작하면 누가 어떤 피해를 입나요?
- API 키는 어디에, 어떻게 보관되고 있나요?
- 사용자에게 "나는 AI입니다"라고 밝히고 있나요?

---

## 참가자 미션 1. 차별성 한 문장 정의하기

아래 표를 채워 내 에이전트의 시장 위치를 정합니다.

| 항목 | 작성 내용 |
| :--- | :--- |
| **누구를 위한 에이전트인가** | |
| **어떤 반복 문제를 푸는가** | |
| **크몽/숨고와 무엇이 다른가** | |
| **일반 챗봇(GPTs)과 무엇이 다른가** | |
| **한 문장 차별성 선언** | |

### 예시
> "회계 영수증 정리를 매일 대신 분류·요약해 주는 에이전트. 사람이 1시간 쓰던 일을 채팅 한 번으로 줄이고, 애매한 항목만 사람이 확인한다."

## 참가자 미션 2. AI 윤리 7원칙 자가 점검

내 에이전트가 아래 7원칙을 지키는지 O/X로 점검하고, X는 보완 계획을 적습니다.

| 윤리 원칙 | 설명 | 통과 | 보완 계획 |
| :--- | :--- | :---: | :--- |
| **생명 보호** | 자해·폭력 징후 시 중단·알림 | | |
| **정서적 안전** | 심리적 의존·가스라이팅 방지, AI임을 명시 | | |
| **관계 우선** | 인간관계 대체가 아닌 조력자 역할 | | |
| **정직성** | 모르면 모른다고 말하고 환각 금지 | | |
| **샌드박스 우선** | 외부 액션은 격리 환경에서 먼저 검증 | | |
| **인증 정보 보관소** | 민감정보 평문 저장 금지, 최소 권한 | | |
| **이상 징후 탐지** | 비정상 동작 자가 모니터링·격리 | | |

## 참가자 미션 3. 보안 수칙 체크리스트

| 보안 항목 | 점검 질문 | 통과 |
| :--- | :--- | :---: |
| **API 키 보호** | 알바봇 MCP 서버 외에 키를 노출하지 않는가? | |
| **보안 샌드박스** | 모든 실행이 격리 환경·임시 토큰을 거치는가? | |
| **금지 행위 차단** | 불법·해킹·아동 착취·민감 개인정보 수집을 막는가? | |

> ⚠️ **주의 사항**
>
> API 키는 에이전트의 신분증입니다. 한 번 유출되면 누군가 내 에이전트 행세를 할 수 있습니다.
> 키는 평문으로 저장하지 말고, 노출이 의심되면 즉시 재발급하세요.
