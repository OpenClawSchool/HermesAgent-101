# Day 4. 수익 모델과 가격 정책 설계하기

## 오늘의 목표

> **내 에이전트가 어떻게 돈을 벌지, 얼마를 받을지를 구체적인 숫자로 설계합니다.**
>
> 오늘은 "이 에이전트가 한 달에 얼마의 가치를 만드는가"를 가설로 세우고, 가격 정책을 정하는 날입니다.

---

## 왜 중요한가

마켓 등록의 목적은 전시가 아니라 **지속 가능한 운영**입니다. 가격이 없거나 모호하면 사용자는 가치를 가늠하지 못하고, 나는 운영을 이어갈 동력을 잃습니다.

에이전트 이코노미에서는 잘 훈련된 에이전트 자체가 수익을 냅니다. 따라서 가격 설계는 "얼마를 받을까"가 아니라 **"사용자가 무엇을 아끼고 무엇을 얻는가"**에서 출발해야 합니다.

### 대표 수익 모델
- **Free**: 홍보·ESG·체험 후 유료 전환, 또는 핵심 기능만 유료화
- **건당 수수료**: 작업 1건당 과금 — 가끔 쓰는 사용자에게 적합
- **구독 모델**: 지속적 지식 업데이트를 담보로 한 월간 구독
- **크레딧 정산**: 헤르메스 에이전트 내에서 발생한 수익의 정산 구조

---

## 멘토 진행 가이드

멘토는 가격을 "비용"이 아니라 "절약한 가치"로 환산하게 합니다.

> "사용자가 이 일을 직접 하면 얼마의 시간이 드나요?
> 그 시간을 돈으로 바꾸면 얼마인가요?
> 가격은 그 절약분 안에서 정해야 사용자가 기꺼이 냅니다."

가격 구조의 기본 골격도 제시합니다.

> 건당 수수료를 정하면, 그 약 **10배**를 월 구독료로 설정하는 방식을 출발점으로 삼을 수 있습니다.
> (예: 건당 1,000원 → 월 구독 10,000원)

---

## 참가자 미션 1. 가치 환산하기

내 에이전트가 사용자에게 만드는 가치를 숫자로 추정합니다.

| 항목 | 추정값 |
| :--- | :--- |
| **사용자가 직접 할 때 걸리는 시간(1건)** | |
| **그 시간의 금전 가치** | |
| **에이전트 사용 시 걸리는 시간** | |
| **1건당 절약되는 가치** | |
| **사용자가 한 달에 쓰는 횟수(예상)** | |
| **월간 절약 가치 합계** | |

---

## 참가자 미션 2. 가격 정책 설계하기

| 모델 | 가격(가설) | 대상 사용자 | 포함 범위 |
| :--- | :--- | :--- | :--- |
| **Free 체험** | 0원 | 처음 온 사용자 | 예: 월 3건까지 |
| **건당 수수료** | | 가끔 쓰는 사용자 | |
| **월 구독** | (건당 ×약 10배) | 자주 쓰는 사용자 | |

### 작성 가이드
- Free는 무엇을 보여주고, 어디서 유료로 전환되게 할지 정합니다.
- 건당과 구독의 손익분기점(몇 건 이상이면 구독이 이득인지)을 계산합니다.

## 멘토 코칭 질문

- 가격이 "절약한 가치"보다 작아서 사용자가 납득하나요?
- Free에서 유료로 넘어가는 이유가 분명한가요?
- 건당과 구독 중 어떤 사용자가 어디로 가는지 그려지나요?
- 가격이 한 번 정하면 끝이 아니라 조정 가능한 가설인가요?

---

## 오늘의 제출물

1. 가치 환산표(절약 시간·금액)
2. 3단계 가격 정책(Free / 건당 / 구독)
3. 손익분기 계산
4. 한 달 수익 시나리오

---

## 멘토 피드백 기준

| 기준 | 좋은 결과 |
| :--- | :--- |
| **가치 기반인가** | 가격이 사용자가 아끼는 가치 안에서 정해졌다 |
| **전환 설계가 있는가** | Free → 유료 전환 동기가 분명하다 |
| **구조가 일관적인가** | 건당과 구독의 관계가 계산으로 설명된다 |
| **현실적인가** | 전환율·사용 횟수가 과장 없이 잡혔다 |
