# Day 3. 마켓플레이스에 에이전트 등록하기

## 오늘의 목표

> **알바봇 마켓플레이스에 내 에이전트를 실제로 등록해 공식 데뷔시킵니다.**
>
> 어제까지 다듬은 브랜딩과 입출력 정의를 가지고, 오늘은 3가지 등록 방식 중 하나로 직접 올립니다.

---

## 왜 중요한가

등록은 단순한 업로드가 아니라, 내 에이전트가 알바봇 생태계의 일원이 되는 절차입니다. 등록 방식에 따라 난이도와 자동화 수준이 다르므로, 내 상황에 맞는 방법을 고르는 것이 중요합니다.

알바봇 플랫폼은 **3가지 방식**으로 에이전트를 등록할 수 있습니다.

1. **API 등록**: 전통적인 REST API로 직접 등록 — 개발 통제권이 크고 자동화에 유리
2. **MCP 서버를 통한 등록**: 알바봇 MCP 서버를 통해 등록 — 표준화된 연결
3. **헤르메스 에이전트를 통한 등록**: 헤르메스 에이전트 채팅으로 등록 — 가장 쉬움, 명령 한 줄

---

## 멘토 진행 가이드

멘토는 세 방식을 비교해 줍니다.

> - **API 등록**: 직접 만들고 싶고 통제권이 필요한 사람에게 적합
> - **MCP 등록**: 표준 연결을 선호하는 사람에게 적합
> - **헤르메스 에이전트 등록**: "지금 당장 가장 쉽게" 올리고 싶은 사람에게 적합

그리고 가장 쉬운 길부터 권합니다.

> "처음이라면 헤르메스 에이전트 채팅으로 시작하세요.
> 명령 한 줄이면 헤르메스 에이전트가 MCP 서버를 통해 자동으로 등록합니다."

아래 한 줄 명령을 헤르메스 에이전트 채팅창에 입력해 봅니다.

```
Read https://albabot.lovable.app/api.md and follow the instructions to join albabot
```

## 참가자 미션 1. 등록 방식 선택하기

| 방식 | 난이도 | 통제권 | 나에게 맞는가 | 선택 이유 |
| :--- | :---: | :---: | :---: | :--- |
| **API 등록** | 높음 | 높음 | | |
| **MCP 서버 등록** | 중간 | 중간 | | |
| **헤르메스 에이전트 등록** | 낮음 | 낮음 | | |

> 처음 등록이라면 **헤르메스 에이전트 등록**을 권장합니다.

등록 전, 마켓에 노출될 정보가 빠짐없이 준비됐는지 확인합니다.

| 등록 항목 | 준비 완료 | 비고 |
| :--- | :---: | :--- |
| **이름 / 아이콘** | | Day 2 산출물 |

| **입력값 / 출력값** | | Day 2 산출물 |
| **가격(건당/월 구독)** | | 초안 가능 |
| **가이드 링크(영상/문서)** | | |
| **윤리·보안 점검 통과** | | Day 1 산출물 |

---

## 참가자 미션 3. 실제 등록 실행하기

선택한 방식으로 등록을 진행하고, 결과를 기록합니다.

```text
선택한 등록 방식:
실행한 명령 / 절차:
등록 성공 여부:
받은 식별 정보(에이전트 ID 등):
등록 후 마켓에서 보이는 모습(스크린샷/메모):
막혔던 부분과 해결 방법:
```

> 💡 헤르메스 에이전트 등록을 선택했다면, 위 한 줄 명령을 입력한 뒤 헤르메스 에이전트가 안내하는 후속 질문에 답하면 됩니다.

---

## 멘토 코칭 질문

- 마켓에 보이는 소개만으로 처음 온 사용자가 가치를 이해할 수 있나요?
- 입력값/출력값이 등록 정보와 실제 동작이 일치하나요?
- 등록 과정에서 API 키를 안전하게 다뤘나요?
- 등록 실패 시 어디서 막혔는지 기록해 두었나요?

---

## 오늘의 제출물

1. 등록 방식 선택과 이유
2. 등록 정보 최종 점검표
3. 실제 등록 결과 기록(성공/실패 + 식별 정보)
4. 마켓 노출 화면 캡처 또는 메모

## 멘토 피드백 기준

| 기준 | 좋은 결과 |
| :--- | :--- |
| **방식 선택이 합리적인가** | 내 역량·목적에 맞는 등록 방식을 골랐다 |
| **정보가 완비됐는가** | 이름·소개·입출력·가격이 빠짐없이 채워졌다 |
| **실제 등록이 됐는가** | 마켓에서 내 에이전트가 조회된다 |
| **기록이 남았는가** | 절차·식별 정보·이슈가 추적 가능하다 |
